Orbit-Transfer · WebRTC browser-to-browser

Fountain codes in WASM over a WebRTC data channel. The sender drags & drops a file and gets a shareable link; the receiver opens it and the transfer runs P2P with no central server (only a tiny signaling room to exchange the SDP). Any file type works — the codec treats it as raw bytes and reconstructs them exactly.

Transfer options & how it works

The codec is rateless: the receiver rebuilds the file from any K+ε of the emitted symbols, in any order. These options stress-test that property.
